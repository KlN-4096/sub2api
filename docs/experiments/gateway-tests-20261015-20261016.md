## 计数口径

- echo A取得state，B实际回带该state；请求成功完成且B不返回新state/返回相同值，记“接受”；返回不同state，记“刷新”。
- 表中“通过/判降”对应工具的echo接受/刷新字段，不是对实际模型权重的识别。
- 鉴权失败、HTTP/SSE错误、超时、票据或有效时区缺失记异常；取消时尚未形成完整配对的网关记未完成。
- 重试次数不是新增网关结果，HTTP200也可能在SSE中返回错误。网关计数与实际HTTP请求数分开。
