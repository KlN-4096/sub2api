## 2026-10-01：echo实现对非200响应的处理

- 受测实现把“未下发新state”直接视为接受。
- 12发观察中出现2次HTTP429；由于响应没有新state头，这2次被实现记成接受。
- 后续本地实现增加HTTP状态检查，非200不形成有效echo结论。
- 这批数据中的2次429不属于模型完成作答的样本。
